Setup

搭建 7 步

照顺序做。所有密钥只贴在平台里，不要发给任何人。

  1. 1

    复制代码

    在 GitHub 搜索开源项目 OpenReply（MIT 授权），复制成你自己的私人仓库。

  2. 2

    开后台（Railway）

    新建项目，加入 Postgres 和 Redis，再从你的仓库部署一个 Worker。

    • 环境变量照项目里的 .env.example 填
    • 随机密钥自己生成，不要用别人的
  3. 3

    开网页后台（Vercel）

    导入同一个仓库，填一样的环境变量，再加上 Resend 的 API Key。部署后会得到一个网址，下面叫「你的网址」。

  4. 4

    开 Meta App

    用途选 Instagram（Instagram 登录版 API）。

    • 权限：instagram_business_basic …_manage_comments …_manage_messages
    • Webhook：你的网址/api/webhook，订阅 comments 和 messages
    • 登录跳转：你的网址/api/instagram/callback
    • 隐私 / 条款 / 数据删除：/privacy /terms /data-deletion
    • App ID 和 App Secret 填回 Vercel 和 Railway
  5. 5

    加测试者并发布

    在 App 角色里加你的 IG 为测试者，到 IG「设置 → 应用和网站」接受邀请，最后把 App 发布（Publish）。

  6. 6

    登录后台

    打开你的网址，输入 Email，点邮件里的登录链接。

  7. 7

    连接 IG

    后台点连接 Instagram。找不到按钮就直接开 你的网址/api/instagram/connect。

检查：后台健康状态里 database、redis、queue、worker 都显示 OK，就是搭好了。

Test

用小号测试

自己账号的留言不会触发。没反应先等 5 分钟，系统会自动补扫。

  • 小号先不关注，在帖子留言关键词
  • 留言下出现公开回复
  • 小号到「消息请求」看到私信，点领取按钮
  • 收到关注提醒，说明关注门槛有效
  • 关注后点「我关注好了」，收到链接
Troubleshoot

常见坑

都是我自己搭的时候真的踩过的。

问题解决
Meta App 名字被拒名字不能有 IG / Instagram
点到「重置 App Secret」点取消，重置会让系统断线
连不上 IG去 IG 里接受测试者邀请
别人留言没反应App 要发布，Webhook 要订阅 comments
自己留言没反应正常，用小号测
登录显示 Unable to sign in用最新那封登录邮件
保存活动报错开场按钮文字没填
粉丝打错关键词多加几种写法
用了几个星期突然停了Railway 试用到期（30 天或额度用完），到期前绑卡升级 Hobby
